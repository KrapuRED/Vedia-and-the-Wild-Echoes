## About Game <img width="25" height="25" alt="Image" src="https://github.com/user-attachments/assets/93c1c452-f50d-408d-a1f1-98669efb24f0" /> 
***Vedia and the Wild Echoes*** is a serious audio-puzzle 3D game where players monitor an Indonesian forest through Passive Acoustic Monitoring (PAM) devices, deciphering wildlife and threat sounds.

Game Engine : Unity 6000.3.19f1
